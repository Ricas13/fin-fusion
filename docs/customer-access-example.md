# Example

A customer may simultaneously see:

- Free Server — active;
- 24-hour Premium Jellyfin trial — active until its trial end;
- Stremio Monthly — active/renewing.

The home page lists all three access records, shows the Free and Premium Jellyfin server credentials separately, and exposes the current Stremio install action. Starting Premium does not delete or suspend Free Server. If the customer stops using Free Server, only Free Server playback is considered by its inactivity policy.
