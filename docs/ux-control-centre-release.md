# CAPTAiNFiN UX control-centre release

This branch is the coherence pass for administrator/customer usability.

## Product rules

- Complexity stays in the implementation; routine workflows use human-readable choices.
- Customer Home answers what is ready and what to do next; advanced details live behind dedicated sections.
- Administrator overrides are explicit, audited and distinguish plan defaults from customer-specific state.
- Permanent access is a first-class lifecycle state, not a collection of unrelated toggles.
- Plan editing exposes only service-relevant configuration.
- Settings ownership is declared centrally so navigation/directory copy does not drift.
- Green means ready/on/allowed, red means off/problem/destructive, amber means pending/attention, and blue means information/action.
