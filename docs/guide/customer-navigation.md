# Customer navigation model

Customer-facing navigation is task based rather than implementation based:

1. Overview
2. Streaming
3. Plans & billing
4. Activity
5. Notifications
6. Security
7. Benefits
8. Help & support

Internal administration concepts such as provisioning, reconciliation, placement, provider event IDs and entitlement composition should not appear in normal customer navigation or primary status copy. Use plain statuses such as **Ready**, **Setting up** and **Needs attention** unless a more specific customer action is required.
