# Stremio service

CAPTAiNFiN can provide a **stream-only Stremio addon** backed by one or more Jellyfin sources. Stremio keeps its normal catalogue and metadata experience; CAPTAiNFiN supplies streams for movies and episodes covered by the customer's plan.

## Source model

Open **Servers → Stremio Sources**.

A Stremio Source can be an external Jellyfin account that CAPTAiNFiN uses as an ordinary user. This is intended for a dedicated Jellyfin account on a server that the operator is authorized to use for Stremio delivery.

To add an external source, enter a friendly source name, the Jellyfin URL, the dedicated Jellyfin username, the Jellyfin password and the source priority.

CAPTAiNFiN uses the username/password only to establish the Jellyfin user session. **The password is discarded immediately.** The returned Jellyfin access token is encrypted at rest with `JELLYFIN_ENCRYPTION_KEY`.

If the Jellyfin operator invalidates that session, the source changes to **Reconnect required**. Reconnect with the username/password to rotate the encrypted session token.

Only connect accounts that you are authorized to automate and use for this delivery purpose. The external Jellyfin operator can still see activity generated by that dedicated account.

## Library selection

Immediately after connecting, CAPTAiNFiN discovers the Movie, TV and Mixed libraries visible to that Jellyfin user.

Choose the libraries that the source should contribute to Stremio. Only selected libraries are placed in the local IMDb lookup index. A library that is not selected is not queried for normal Stremio title matching.

Changing the library selection queues a new full reconciliation and removes locally indexed entries from deselected libraries.

## Index schedule

CAPTAiNFiN deliberately keeps indexing lightweight:

- **first setup / library change:** full reconciliation;
- **every 6 hours:** incremental sync using Jellyfin's last-saved timestamp filter;
- **at least every 7 days:** full reconciliation to catch deletes and unusual metadata changes; and
- **manual:** **Sync now** queues a full reconciliation.

Sources are indexed sequentially. Index requests use modest pages, do not fetch artwork, and store only metadata required for Stremio matching. Authentication errors stop repeated requests and mark the source for reconnect instead.

The source page shows the selected library count, index state, indexed IMDb title count, last sync, next incremental sync and last full reconciliation.

## Plan source selection

For a Stremio or Jellyfin + Stremio plan, open **Commerce → Plans → plan → Delivery**.

The **Stremio sources** section lets you select one or more external sources and assign a priority. Lower priority numbers are tried first.

Once a plan has explicit source mappings, they are a strict allow-list. CAPTAiNFiN does **not** silently use an unrelated source if every selected source is unavailable.

Plans created before this source model can keep the legacy CAPTAiNFiN-managed Jellyfin delivery path until explicit Stremio Sources are selected.

## External-source playback security

CAPTAiNFiN never sends the external Jellyfin account token to the subscriber's Stremio client.

The data path for an external source is:

```text
Stremio
  → CAPTAiNFiN manifest/stream endpoint
  → customer entitlement + source allow-list check
  → CAPTAiNFiN local IMDb index
  → Jellyfin playback metadata using the encrypted source token
  → CAPTAiNFiN playback URL returned to Stremio
  → CAPTAiNFiN proxies the media request to Jellyfin with the source token server-side
```

This protects the dedicated upstream Jellyfin account from being extracted and reused by subscribers. The trade-off is that external-source video traffic passes through the CAPTAiNFiN host, so its network bandwidth and latency matter for these streams.

## Managed Jellyfin compatibility

CAPTAiNFiN can still use Jellyfin servers it administers directly. That older path creates a dedicated hidden `cf_stremio_...` Jellyfin identity for the customer and can apply Jellyfin-side stream and policy restrictions.

The legacy managed path uses `STREMIO_JELLYFIN_TOKEN_KEY` for its restricted Jellyfin token. **External-source-only plans do not require that Stremio-specific key**; their upstream session tokens use the existing `JELLYFIN_ENCRYPTION_KEY`.

Once a plan explicitly selects external Stremio Sources, CAPTAiNFiN does not create the hidden managed Jellyfin Stremio identity merely to satisfy the addon runtime.

## Runtime

The runtime switch lives on **Servers → Stremio Sources**.

CAPTaINFiN refuses to enable customer Stremio delivery until at least one usable source has a selected library and a ready, non-empty index. Runtime changes are stored in platform settings and audit logged.

`STREMIO_RUNTIME_ENABLED` exists only as an upgrade-compatibility fallback for older installations that have not yet saved the browser-managed runtime state.

## Customer setup

If the customer's effective plan includes Stremio:

1. Sign in to the CAPTaINFiN customer portal.
2. Open **Stremio**.
3. Choose **Create installation**.
4. Use **Install in Stremio**, or copy the manifest URL into Stremio manually.
5. Open a movie or episode in Stremio. CAPTaINFiN stream choices appear alongside the customer's other addons.

The raw addon credential is shown only when created or rotated. CAPTaINFiN stores a one-way hash rather than the raw installation credential. Rotating an installation invalidates the previous addon URL. Revoking the installation invalidates the addon credential immediately.

## Stream limits

CAPTaINFiN applies the plan's concurrent-stream policy before serving addon access and retains normal playback/activity enforcement. On managed Jellyfin delivery the hidden Jellyfin identity can also receive a matching Jellyfin-side session limit. An external Jellyfin source remains subject to whatever limits the upstream operator configured for the dedicated source account.

## Stream names

CAPTaINFiN enriches stream choices with source/quality information where Jellyfin exposes it. The addon remains stream-only; it does not replace Stremio's catalogue.

## Launch checklist

1. Add a dedicated Jellyfin account under **Servers → Stremio Sources**.
2. Select only the libraries you want indexed.
3. Wait for the first index to show **Ready** and check that the title count is sensible.
4. Enable the Stremio runtime.
5. Create or edit the Stremio/bundle plan and explicitly select its source(s).
6. Use a controlled test customer to create an installation.
7. Test movie and episode playback on each Stremio client you intend to support.
8. Only then make the Stremio product publicly visible.
