# UX control-centre merge checklist

- [ ] Customer 360 routine controls use human-readable plan/server choices.
- [ ] Permanent access is enforced by lifecycle automation and visible in Customer 360.
- [ ] Manual Jellyfin assignment is audited and reconciled safely.
- [ ] Customer Home is action-first and hides advanced details by default.
- [ ] Plan editor tabs are service-aware.
- [ ] Bulk plan/server workflows do not ask for UUIDs.
- [ ] Settings directory is backed by central ownership metadata.
- [ ] Marketing consent cannot be casually granted by an administrator.
- [ ] Semantic colours/toggles are consistent.
- [ ] Clean-install and upgrade migrations pass.
- [ ] Customer Portal, Provisioning, CI, Release Integrity and browser journeys are green.
