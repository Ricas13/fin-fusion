# Menu relevance rationale

This file records why the current primary navigation earns a sidebar slot.

- **Dashboard** — current business/streaming state.
- **Needs Attention** — actionable exceptions requiring an operator decision.
- **Search** — cross-domain navigation utility.
- **Customers / Resellers / Playback & Activity** — people and their service usage.
- **Servers / Libraries** — infrastructure inventory and media entitlement sources.
- **Commerce Overview / Plans / Payments / Discounts / Referrals** — distinct commercial jobs.
- **Provisioning / Jobs / Audit & events** — automated service state, scheduled work, and historical operational evidence.
- **General / My Profile / Notifications / Branding / Integrations / Security / Operations / Backups / Advanced** — configuration domains with different ownership and risk levels.

Pages intentionally *not* promoted to the sidebar:

- **Policy Drift** — diagnostic/compliance detail of Provisioning.
- **Notification Delivery health** — diagnostic detail of Notifications.
- **My Notifications** — personal subpage of My Profile.
- **Billing / Provider mappings** — sub-workflow of Payments.
- **Settings Commerce** — duplicate of the primary Commerce group.

Future reviews should prefer removing or nesting a destination when it cannot answer a distinct operator question in one sentence.
